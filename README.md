# WP Media Toolkit

一个轻量、独立的 WordPress 媒体增强插件，用于媒体库列表增强、可配置上传策略、Simple Local Avatars 补丁，以及前台图片点击预览。

## 基本信息

- 作者：`biancaplus`
- 当前版本：`1.0.0`
- WordPress：`6.0+`
- PHP：`7.4+`
- 许可证：[GPL-2.0-or-later](https://www.gnu.org/licenses/gpl-2.0.html)
- 页面构建器：无依赖（图片预览可通过后台配置或 PHP API 使用）

## 功能

- 媒体库列表增加文件大小、分辨率、引用次数列，并支持异步加载引用次数。
- 附件编辑页展示图片使用位置（文章、特色图、meta、option、用户资料等）。
- 可配置上传大小硬限制（KB）及后台提示文案。
- 以「禁止列表」方式限制常见上传格式（含 JPG、PNG、WebP、PDF、CSV 等）。
- 可选允许管理员上传 SVG（不做内容消毒，设置页有风险提示）。
- 可选启用 Simple Local Avatars 补丁：纠正环境切换后的头像 URL，并避免更换头像时误删媒体库文件。
- 前台图片预览灯箱：缩放、左右切换；排除 emoji / `data-type="icon"` 等图标。
- 预览样式自包含，不依赖主题 Tailwind。
- 提供公共 API：`wpmt_image_preview_init()`，与后台容器 ID 合并去重。
- 各功能默认关闭（安全默认）；卸载时可选择是否删除插件设置数据。

## 安装

1. 将 `wp-media-toolkit` 目录上传至 `/wp-content/plugins/`。
2. 在 WordPress 后台的「插件」页面启用 **WP Media Toolkit**。
3. 前往「媒体 > 媒体库设置增强」按需开启列表增强、上传策略与补丁。
4. 前往「媒体 > 图片预览功能」启用预览并填写容器元素 ID。

启用插件后默认不会改变站点既有行为，需在设置页逐项打开。

## 媒体库设置增强

路径：`媒体 > 媒体库设置增强`

| 选项 | 说明 |
|------|------|
| 列表增强 | 文件大小、分辨率、引用次数；附件页「使用位置」 |
| 上传大小限制 | 开关 + 最大 KB；开启后对上传做硬限制并显示提示 |
| 禁止上传的格式 | 多选禁止列表；勾选表示不允许上传该格式 |
| 允许 SVG 上传 | 仅 `manage_options` 用户可传；首版不做 SVG 消毒 |
| Simple Local Avatars 补丁 | 未安装 SLA 时开启也无害 |
| 卸载时删除数据 | 默认关闭；勾选后卸载会清除本插件 option |

## 图片预览功能

路径：`媒体 > 图片预览功能`

1. 勾选「启用图片点击预览」。
2. 在「容器元素 ID」中每行填写一个元素 ID（无需写 `#`）。
3. 仅这些容器内部的 `img` 会启用灯箱；容器外图片不受影响。

也可在主题或插件中调用：

```php
<?php if ( function_exists( 'wpmt_image_preview_init' ) ) { wpmt_image_preview_init( 'your-content-id' ); } ?>
```

API 注册的容器会与后台列表合并去重。即使后台总开关关闭，仅通过 API 注册时也会加载预览资产。

## 卸载

默认卸载**不会**删除设置。

仅在「媒体库设置增强」中勾选「卸载插件时删除本插件的全部设置数据」后，卸载才会清除：

- `wpmt_media_settings`
- `wpmt_preview_settings`

## 常见问题

### 是否依赖 Elementor 或其他页面构建器？

不依赖。列表与上传策略在 WordPress 后台生效；图片预览通过容器 ID 或 PHP API 绑定任意页面 DOM。

### 是否依赖 Simple Local Avatars？

不强制依赖。未安装时开启「SLA 补丁」不会报错；安装后补丁才会作用于头像 meta。

### 为什么启用插件后媒体库没有变化？

各功能默认关闭。请到「媒体库设置增强」「图片预览功能」中打开对应开关并保存。

### SVG 上传安全吗？

WordPress 默认不允许 SVG。本插件开启后仅允许管理员上传，且**不做**文件内容消毒。请勿对不可信来源开启；内容消毒可作为后续版本能力。

### 禁止列表和「允许 SVG」如何同时理解？

SVG 不进入禁止列表，只由「允许 SVG 上传」控制。其它格式勾选即禁止。

### 图片预览点不开？

确认已启用预览、页面中存在对应 `id` 的容器，且点击的是该容器内的图片（非 icon / emoji）。
